# Registro de decisiones de arquitectura (ADR)

Los ADR documentan **contexto, decisión, alternativas, consecuencias y estado**. No se reescriben decisiones aceptadas: se sustituyen con otro ADR si cambian.

- [ADR-0001 · Arquitectura tecnológica y separación de ambientes](ADR-0001-stack.md)
- [ADR-0002 · Prototipo sin pagos ni sorteos reales](ADR-0002-demo-sin-pagos.md)

## Plantilla para nuevas decisiones

**Estado:** propuesta / aceptada / sustituida  
**Fecha:** AAAA-MM-DD  
**Contexto:** problema y restricciones  
**Decisión:** alternativa seleccionada  
**Alternativas:** opciones descartadas y por qué  
**Consecuencias:** impactos, riesgos y trabajo pendiente  
**Revisión:** evidencia y responsables cuando existan
